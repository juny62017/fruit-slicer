#  Fruit Slicer

A simple  fruit slicing game made using HTML, CSS, JavaScript...

Move your cursor over the falling fruits to slice them
earn points
and try not to let them fall
You have three lives
and the game ends after missing three fruits.


## THEME
IT IS AN ENDLESS GAME
BECAUSE THERE IS NO ENDING LEVEL... YOU JUST GO AND GO
AND JUST THERES 3 LIVE SYSTEM SO YOU CAN PLAY SERIOUSLY 


## Features

* THERE IS RANDOM FRUITS FALLING FROM SKY 
* FRUITS FALL FROM DIFFERENT SPEED AND SHAPE
* YOU CAN SLICE FRUITS BY JUST MOVING CURSOR THROUGH THEM 
* SCORE GETS INCREASED WHENEVER THE FRUITS GET CUT
* SOUND SYSTEM ADDED... 
* EXPLOSION SOUND AFTER SOME FRUIT CUT
* THERE IS 3 LIVE SYSTEM
* START AND RESET OPTION


## How to Play

1. Click the *tart Game button.
2. Move your cursor over a falling fruit to slice it.
3. Each sliced fruit gives you one point.
4. Missing a fruit removes one life.
5. The game ends when all three lives are lost.
6. Click Start Game again to play another round.

## Tech USED
